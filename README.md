# Onlline-course-website
Course Website – Front-End Development Task

**Project Overview**

This project is a responsive Course Website created as part of a Front-end Development Internship task. The website is designed to provide information about online courses and allows users to contact through a validated contact form.

**Objective**

The objective of this project is to demonstrate basic front-end development skills, including page structuring, responsiveness, and JavaScript interactivity.

**Features**

•	Responsive design for mobile, tablet, and desktop screens

•	Hamburger navigation menu for better mobile usability

•	Multi-page layout (Home, About, Contact)

•	Contact form with client-side validation

•	Clean and readable code structure

**Technologies Used**

•	HTML5 – Structure of web pages

•	CSS3 – Styling and responsive layout

•	JavaScript – Interactivity and form validation

•	GitHub – Version control and project hosting
